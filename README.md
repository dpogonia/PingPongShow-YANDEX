# PingPongShow

Пинг-понг для iPhone. Учебный проект бесплатной части курса iOS-разработки Яндекс Практикума: первое приложение на Swift и UIKit.

В [программе курса](https://code.s3.yandex.net/Mobile/iOS/Syllabus/Syllabus_Yandex_Practicum_iOS_Developer.pdf) это «Игра Pong».

## Что умеет приложение

Мяч двигается через UIKit Dynamics. Своя ракетка следует за пальцем, верхняя играет за компьютер. Счёт и лучший результат видны на экране.

Сложность компьютера: легко, обычно, сложно и beast. Чем дольше идёт матч, тем быстрее отвечает ракетка соперника. Удары звучат по-разному, на фоне играет музыка.

## Стек

UIKit, UIKit Dynamics, AVFoundation, Storyboard. iOS 14, портретная ориентация.

## Запуск

```bash
git clone https://github.com/dpogonia/PingPongShow.git
cd PingPongShow
open PingPongShow.xcodeproj
```

Запустите схему **PingPongShow** на симуляторе iPhone.
