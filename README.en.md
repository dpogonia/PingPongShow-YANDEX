# PingPongShow

Pong for iPhone. A project from the free part of the Yandex Practicum iOS course: a first app in Swift and UIKit.

The [course syllabus](https://code.s3.yandex.net/Mobile/iOS/Syllabus/Syllabus_Yandex_Practicum_iOS_Developer.pdf) lists it as the Pong game.

## What it does

The ball moves with UIKit Dynamics. Your paddle follows a finger, and the top paddle plays for the computer. The score and the best result stay on screen.

Computer difficulty: easy, regular, hard, and beast. The longer the match goes, the faster the opponent answers. Hits have their own sounds, and music plays in the background.

## Stack

UIKit, UIKit Dynamics, AVFoundation, Storyboard. iOS 14, portrait only.

## Run

```bash
git clone https://github.com/dpogonia/PingPongShow-Yandex.git
cd PingPongShow-Yandex
open PingPongShow.xcodeproj
```

Run the **PingPongShow** scheme on an iPhone simulator.
